In Section \ref{sec:two-party}, we analyzed $\TRAV_2$, the two-party traversal problem. We now study the $k$-party version, denoted $\TRAV_k$, with $k \geq 2$.

\begin{definition}
\label{def:multi-party-trav}
Let $G=(V,E)$ be an undirected graph with designated start and end vertices $v,w \in V$, where $|V|=n$. There are $k$ players, and player $i \in [k]$ owns a vertex subset $V_i \subseteq V$. The edge set owned player $i$ is $E_i = \{(a,b) \in E \mid \{u,v\} \cap V_i \neq \emptyset\}$. Thus player $i$ owns a subgraph $G_i = (V_i,E_i)$. Given a fixed $G$, start vertex $v$, and end vertex $w$ known to all players, an instance of $\TRAV_k$ is defined as follows:
\begin{align}
\TRAV_k(G_1,\ldots,G_k) &: \bigtimes_{i=1}^k \{0,1\}^n \to \{0,1\} \\
\TRAV_k(G_1,\ldots,G_k) &=
\begin{cases}
1 & \text{if there is a path from } v \text{ to } w \text{ in } \bigcup_{i=1}^k G_i,\\
0 & \text{otherwise.}
\end{cases}
\end{align}
\end{definition}

\begin{definition}
\label{def:k-party-disj}
The $k$-party disjointness problem $\DISJ_k$ is defined as follows: Each player $i\in[k]$ has input $x^{(i)}\in\{0,1\}^n$, interpreted as a subset $S_i = \{j\in[n] \mid x^{(i)}_j=1\} \subseteq [n]$. Define
\begin{align}
\DISJ_k(x^{(1)},\ldots,x^{(k)}) &: \bigtimes_{i=1}^k \{0,1\}^n \to \{0,1\} \\
\DISJ_k(x^{(1)},\ldots,x^{(k)}) &=
\begin{cases}
1 & \bigcap_{i=1}^k S_i=\emptyset, \\
0 & \bigcap_{i=1}^k S_i\neq\emptyset.
\end{cases}
\end{align}
\end{definition}

It is well known that $D(\DISJ_k) = \Omega(nk)$ and $R(\DISJ_k) = \Omega(nk)$ \parencite{MultipartyDisjointness}.

\begin{claim}
\label{claim:k-party-disj-to-trav}
$\TRAV_k$ is at least as hard as $\DISJ_k$. Furthermore, $D(\TRAV_k) = \Theta(nk)$ and $R(\TRAV_k) = \Theta(nk)$.
\end{claim}

\begin{proof}
Let $(x^{(1)},\dots,x^{(k)})$ be an input to $\DISJ_k$ with $x^{(i)}\in\{0,1\}^n$. The high level idea is similar to Claim \ref{claim:disjoint-trav-bound}: we build a $\TRAV_k$ instance from a chain of $n$ multi-party disjointness gadgets. 

\paragraph{Multi-party disjointness gadget.} For each index $j \in [n]$, create vertices $L_j$, $R_j$, and $M_j$. All players own $L_j$ and $R_j$. Furthermore, player $i$ owns $M_j$ if and only if $x^{(i)}_j = 0$. Then there is a valid path from $L_j$ to $R_j$ if and only if at least one player has $x_j^{(i)} = 0$. Equivalently, there is no such path if and only if all players have $x_j^{(i)} = 1$.

\paragraph{Reduction to $\TRAV_k$.} We construct a graph $G$ by chaining $n$ copies of the multi-party disjointness gadget, connecting $R_{l} = L_{l+1}$ for all $l \in[n-1]$. Set the start vertex $v = L_1$ and end vertex $w = R_n$. Then there is a path from $v$ to $w$ in $\bigcup_{i=1}^k G_i$ if and only if every gadget is traversable (that is, there is a path $L_j$ to $R_j$ for all $j \in [n]$). This means that for every $j$, there is some player with $x_j^{(i)} = 0$, so $\bigcap_{i=1}^k S_i = \emptyset$. In other words, a path from $v$ to $w$ witnesses that every element in $[n]$ is missing from at least one subset $S_i$.

We conclude the proof by noting that the construction uses $\Theta(n)$ vertices and edges. Hence $D(\TRAV_k) =\Omega(nk)$ and $R(\TRAV_k) = \Omega(nk)$.

For upper bounds, consider the trivial protocol where players $2,\ldots,k$ send their input to player $1$ in $(k-1)n = \Theta(nk)$ bits. Then Player $1$ can compute the answer. This trivial protocol works in both the deterministic and randomized setting. This gives $D(\TRAV_k) = \Theta(nk)$ and $R(\TRAV_k) = \Theta(nk)$.
\end{proof}

Informally, this tells us that adding more players does not make traversal an easier problem in terms of deterministic and public randomized communication complexity.
