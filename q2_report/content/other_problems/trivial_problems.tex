\paragraph{1. Unbounded Traversal with Common Input (``0-communication'' triviality).}

\textbf{Model.}
Fix any class of finite graphs $\mathcal{G}$ and any set of queries $\mathcal{Q}$.
An instance is a pair $(G,q)$ with $G\in\mathcal{G}$ and $q\in\mathcal{Q}$.
Let $\mathsf{Ans}:\mathcal{G}\times\mathcal{Q}\to\{0,1\}$ be any decision predicate.

Consider a two-party communication problem in which
Alice's input is $x=(G,q)$ and Bob's input is $y=(G,q)$ \emph{identically the same string}.
(Equivalently, $y=x$ is promised.)

Define the Boolean function
\[
f_{\mathrm{common}}(x,y) \;=\; \mathsf{Ans}(G,q)
\quad\text{under the promise } x=y=(G,q).
\]

\textbf{Claim (Triviality).}
$D(f_{\mathrm{common}})=0$ and $N^1(f_{\mathrm{common}})=N^0(f_{\mathrm{common}})=0$.

\textbf{Proof.}
Since $x=y$, both parties can compute $\mathsf{Ans}(G,q)$ locally with unbounded computation.
Therefore a deterministic protocol that sends no bits exists: each outputs $\mathsf{Ans}(G,q)$.
Hence $D(f_{\mathrm{common}})\le 0$, so $D(f_{\mathrm{common}})=0$.

For nondeterminism, a nondeterministic protocol may also send no bits:
each party ignores the certificate and outputs $\mathsf{Ans}(G,q)$.
Thus $N^1(f_{\mathrm{common}})=N^0(f_{\mathrm{common}})=0$.

\textbf{Lower bound.}
Communication complexity is always $\ge 0$ by definition, so the upper bound is tight.

\textbf{Embedding note.}
Any nontrivial lower bound requires \emph{private information} (e.g., Alice and Bob see different parts of $G$,
or have different start locations/vision transcripts). Without private inputs, $f$ collapses to a one-input problem,
and communication is identically $0$.

\paragraph{2. Black Hole Search on a Path (communication $\Theta(\log n)$).}

\textbf{Goal.}
Formalize a decision/identification task where the \emph{only} uncertainty is the black-hole location,
and determine the deterministic and nondeterministic communication needed.

\textbf{Instance.}
Let $P_n$ be the path graph on vertices $\{1,2,\dots,n\}$ with edges $(i,i+1)$.
There is an unknown black-hole vertex $b\in[n]$.
A probe (agent) that \emph{visits} $b$ is destroyed and sends no further messages.
If it never visits $b$, it survives and may report back.

\textbf{Communication model.}
Alice and Bob cooperate and can launch probes from vertex $1$.
A probe may walk deterministically along the path; upon returning to $1$ alive,
it can send a \emph{single bit} ``alive'' to both parties.
(If destroyed, no bit is sent.)
The \emph{communication cost} is the total number of bits ever successfully sent by surviving probes.

\textbf{Problem (BH-LOC).}
The output is the \emph{exact} index $b\in[n]$.
Equivalently, define $f_b$ as the function mapping the unknown $b$ to its binary encoding,
and ask the parties to output $b$.

\textbf{Claim.}
The deterministic communication complexity to identify $b$ satisfies
\[
D(\mathrm{BH\text{-}LOC}_n) \;=\; \Theta(\log n).
\]

\textbf{Upper bound (protocol achieving $O(\log n)$ bits).}
Maintain an interval $I=[L,R]$ known to contain $b$ (initially $[1,n]$).
Repeat while $L<R$:
let $m=\left\lfloor\frac{L+R}{2}\right\rfloor$.
Launch a probe that walks from $1$ to $m$ and then returns to $1$ along the same path.
\begin{itemize}
\item If the probe returns alive, then it never visited $b$, so $b\notin[1,m]$ and hence $b\in[m+1,R]$.
Update $L\leftarrow m+1$.
\item If the probe is destroyed, it must have visited $b$ on the way to $m$, so $b\in[L,m]$.
Update $R\leftarrow m$.
\end{itemize}
Each iteration produces at most one bit of communication (alive/no-alive, where ``no-alive'' is inferred from silence).
The interval size halves each time, so there are at most $\lceil\log_2 n\rceil$ iterations and thus
$O(\log n)$ communicated bits. When $L=R$, output $b=L$.

\textbf{Lower bound (why $\Omega(\log n)$ bits are necessary).}
Any correct deterministic protocol must distinguish among $n$ possible black-hole locations.
Each bit of communication can create at most a factor-$2$ branching in the transcript.
If at most $c$ bits are communicated, there are at most $2^c$ possible transcripts,
hence at most $2^c$ different outputs can be forced.
Correctness for all $b\in[n]$ requires $2^c\ge n$, so $c\ge \lceil\log_2 n\rceil$.
Thus $D(\mathrm{BH\text{-}LOC}_n)\ge \log_2 n$, matching the protocol up to constants.

\textbf{Nondeterministic complexity.}
To certify that the black hole is at location $b$, a prover can send the index $b$ using $\lceil\log_2 n\rceil$ bits,
after which the parties verify by running the above test specialized to $b$ (e.g., test $m=b$ and $m=b-1$).
Hence $N^1(\mathrm{BH\text{-}LOC}_n)=\Theta(\log n)$.
Similarly $N^0$ is also $\Theta(\log n)$ since the output is an index among $n$ possibilities.

\textbf{Embedding used for the lower bound.}
This lower bound is the standard \emph{information} bound:
distinguishing $n$ cases requires $\Omega(\log n)$ bits.
Equivalently, one can embed the INDEX function by letting $b$ encode an $\log n$-bit string.


\paragraph{3. Graph Isomorphism as Equality under a Rigidity Promise (communication $\Theta(n^2)$).}

\textbf{Inputs.}
Fix $n$.
Alice receives an $n$-vertex labeled simple graph $G$ via its adjacency matrix $A\in\{0,1\}^{n\times n}$
(with zeros on the diagonal and symmetry).
Bob receives an $n$-vertex labeled simple graph $H$ via adjacency matrix $B\in\{0,1\}^{n\times n}$.
Let $\mathrm{GI}_n(G,H)=1$ iff $G$ and $H$ are isomorphic (i.e., $A = PBP^\top$ for some permutation matrix $P$).

\textbf{Why unrestricted GI is not ``just equality''.}
Without restrictions, $\mathrm{GI}_n(G,H)=1$ may hold even when $A\ne B$ as strings,
so it is \emph{not} literally the Equality function on the adjacency matrices.

\textbf{Promise family (Rigid graphs).}
Let $\mathcal{R}_n$ be any family of labeled graphs on $[n]$ with \emph{trivial automorphism group}:
for every $G\in\mathcal{R}_n$, the only permutation $\pi$ with $\pi(G)=G$ is the identity.
(Equivalently: $G$ has no nontrivial relabeling that preserves adjacency.)

Define the \emph{promised} problem:
\[
\mathrm{GI}^{\mathcal{R}}_n(G,H)=\mathrm{GI}_n(G,H)
\quad \text{with the promise } G,H\in\mathcal{R}_n.
\]

\textbf{Claim (Triviality-to-equality under the promise).}
On $\mathcal{R}_n\times \mathcal{R}_n$, isomorphism equals literal equality:
\[
\forall G,H\in\mathcal{R}_n,\qquad \mathrm{GI}_n(G,H)=1 \iff G=H \text{ (as labeled graphs)}.
\]

\textbf{Proof.}
If $G=H$ as labeled graphs, then clearly they are isomorphic (identity permutation), so $\Rightarrow$ holds.
Conversely, suppose $\mathrm{GI}_n(G,H)=1$.
Then there exists a permutation $\pi$ with $\pi(H)=G$.
Apply $\pi^{-1}$ to both sides: $H=\pi^{-1}(G)$, so $G$ is isomorphic to itself via $\pi\circ\sigma$
for some $\sigma$ mapping $G$ to $H$; more simply, since $G$ and $H$ are isomorphic,
there exists a bijection $\varphi$ from $V(G)$ to itself that preserves adjacency between $G$ and $G$
when composing the two isomorphisms $G\to H$ and $H\to G$.
This yields a graph automorphism of $G$.
Rigidity of $G$ forces this automorphism to be identity, hence the original isomorphism must be identity on labels,
so $G=H$ as labeled graphs. 

\textbf{Deterministic communication complexity.}
Let $m=\binom{n}{2}$ be the number of independent adjacency bits.
Then, under the promise,
$\mathrm{GI}^{\mathcal{R}}_n$ is exactly $\mathrm{EQ}_m$ (equality on $m$ bits).
Therefore
\[
D(\mathrm{GI}^{\mathcal{R}}_n)=\Theta(m)=\Theta(n^2).
\]

\textbf{Upper bound protocol (achieves $O(n^2)$).}
Alice sends her adjacency matrix (or just the upper triangle) to Bob using $m$ bits.
Bob checks if his matrix equals Alice's; if yes output $1$, else $0$.
Cost $m=\Theta(n^2)$ bits.

\textbf{Lower bound (embedding of $\mathrm{EQ}_m$).}
Equality on $m$ bits has deterministic communication complexity $D(\mathrm{EQ}_m)=m$:
Alice must reveal enough to distinguish her $m$-bit string from all others.
Formally, if fewer than $m$ bits are sent, by pigeonhole there exist distinct $x\ne x'$ producing the same transcript,
and Bob cannot distinguish $(x,x)$ from $(x',x)$, causing an error on equality.
Since $\mathrm{GI}^{\mathcal{R}}_n$ equals $\mathrm{EQ}_m$ under the promise, the same lower bound applies.

\textbf{Nondeterministic bounds.}
For equality:
\begin{align*}
N^1(\mathrm{EQ}_m)&= \Theta(m) &&\text{(certificate is the full string)}, \\
N^0(\mathrm{EQ}_m)&= \Theta(\log m) &&\text{(certificate is an index of a differing bit)}.
\end{align*}
Thus
\[
N^1(\mathrm{GI}^{\mathcal{R}}_n)=\Theta(n^2),
\qquad
N^0(\mathrm{GI}^{\mathcal{R}}_n)=\Theta(\log n).
\]

\textbf{Problems embedded to prove bounds.}
The tight deterministic bound uses an embedding of $\mathrm{EQ}_m$.
The nondeterministic $0$-certificate bound uses embedding of $\mathrm{NEQ}_m$ via an index witness.

\paragraph{4. Multi-agent Sokoban with Shared Instance (communication $0$).}

\textbf{Sokoban instance.}
Fix a grid $[W]\times[H]$ with walls $S\subseteq [W]\times[H]$.
There are $k$ labeled movable blocks with initial positions $B_1,\dots,B_k\in ([W]\times[H])\setminus S$
and $k$ labeled goal cells $G_1,\dots,G_k\in ([W]\times[H])\setminus S$.
There are $k$ agents with initial positions $A_1,\dots,A_k$.
A move allows an agent to step to a neighboring non-wall cell;
if it steps into a block cell, it may push the block one step forward provided the destination cell is empty and non-wall.
(Any agent may push any block.)

\textbf{Winning condition.}
The players win iff there exists a finite sequence of legal moves after which
the set of block positions equals the set of goal positions:
\[
\{B_1^{\mathrm{final}},\dots,B_k^{\mathrm{final}}\}=\{G_1,\dots,G_k\}.
\]
(Equivalently, blocks can be assigned bijectively to goals at the end; labels do not matter.)

\textbf{Communication problem.}
Alice's input and Bob's input are \emph{identical}: the entire Sokoban instance
\[
x=y=(W,H,S,(A_i)_{i=1}^k,(B_i)_{i=1}^k,(G_i)_{i=1}^k).
\]
Define
\[
f_{\mathrm{Soko}}(x,y)=1 \iff \text{the instance is solvable (a winning move sequence exists).}
\]

\textbf{Claim (Triviality).}
$D(f_{\mathrm{Soko}})=0$ and $N^1(f_{\mathrm{Soko}})=N^0(f_{\mathrm{Soko}})=0$.

\textbf{Proof.}
Because $x=y$, both parties have the \emph{entire} instance.
With unbounded computation, each can decide solvability locally (e.g., by exhaustive search over the finite state space).
Hence there is a protocol with zero communication: each outputs the computed answer.
Thus $D(f_{\mathrm{Soko}})\le 0$, so $D(f_{\mathrm{Soko}})=0$.

For nondeterminism, likewise communication is unnecessary:
each party can ignore any certificate and compute the answer directly.
So $N^1=N^0=0$.

\textbf{Tie-breaking discussion (not needed for solvability).}
If the task were instead to \emph{execute} a solution without communication,
the agents can still pre-agree on a deterministic rule to avoid symmetry (e.g., lexicographic priorities over agents/cells),
because the full instance is common knowledge; but for the \emph{decision} version, this is irrelevant.

\textbf{Lower bound.}
Again, communication is always $\ge 0$, so the bound is tight.

\textbf{Embedding note.}
To force large communication, one must distribute the instance (e.g., each party sees disjoint subsets of walls/blocks/goals,
or private observation transcripts). Under such partitions, one can embed $\mathrm{DISJ}$ or $\mathrm{EQ}$
by encoding bits into whether certain corridors/locks exist, producing $\Omega(n)$ or $\Omega(n^2)$ lower bounds.
Without private inputs, the decision problem has $0$ communication complexity.
