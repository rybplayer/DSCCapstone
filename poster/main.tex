\begin{block}{Basic Example: Equality}

There are two players, traditionally called \textbf{Alice} and \textbf{Bob}.  
\begin{itemize}
    \item Alice holds input $x$
    \item Bob holds input $y$
    \item Together, they want to compute a function $f(x,y)$
\end{itemize}
They are allowed to send messages (bits) back and forth. The goal is to
minimize the total number of bits communicated.
\\
\textbf{Equality} wishes to compute if two bit-strings are the same:
\\


\begin{figure}[H]
\centering
\begin{tikzpicture}[
  scale=0.75,                
  transform shape,          
  node/.style={draw, rounded corners, minimum width=2.5cm, minimum height=0.8cm},
  level distance=2.5cm,
  sibling distance=10cm
]

\node[node] {Is $x_1 = y_1$?}
  child { node[node] {if $\neq$: output $0$} }
  child { node[node] {if $=$: Is $x_2 = y_2$?}
    child { node[node] {if $\neq$: output $0$} }
    child { node[node] {$\dots$}
      child { node[node] {if $\neq$: output $0$} }
      child { node[node] {if $=$: Is $x_n = y_n$?}
        child { node[node] {if $\neq$: output $0$} }
        child { node[node] {if $=$: output $1$} }
      }
    }
  };
\end{tikzpicture}
\caption {Visual for Equality Proof}
\end{figure}

Figure 3 demonstrates how, in the worst case, we must check every bit, since if
every bit except $x_n$ and $y_n$ are the same, we will have to check all $n$
bits to show equality.  Thus, the deterministic communication complexity of
Equality is $D(\text{EQ}) = n$

\end{block}
