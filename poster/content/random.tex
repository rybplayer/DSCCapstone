\begin{block}{Set Disjointness}

	To find a lower bound for a random algorithm we can no longer rely on
	embedding Equality, as random algorithms for equality can be bounded
	as low as $\Theta(1)$. Thus, we turn to Set Disjointness:

	\[
		\textsc{DISJ}(x,y)=
		\begin{cases}
			1 & x \cap y \neq \emptyset, \\
			0 & x \cap y = \emptyset.
		\end{cases}
	\]

	Set Disjointness gives each player some number of elements from a set,
	and asks if the players have any elements in common. If so, the
	protocol outputs 0, and 1 otherwise. Set Disjointness is useful when
	studying random algorithms since it has been shown that it requires
	asymptotically \textbf{maximal \emph{randomized} communication}.

\end{block}

\begin{block}{Other Variants and Multi-Party Graph Traversal}
	We also show that some other variants of the two-player Traversal Problem with additional restrictions remain maximally hard in terms of communication complexity.
    
    In addition, these results generalize to
	three or more players as well. Specifically, we show that the traversal problem is still maximally hard in both the deterministic and random case for $k \geq 2$ players.
\end{block}
