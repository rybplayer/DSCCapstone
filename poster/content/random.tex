Let’s think about another approach. What if we allow randomness and small errors? Could the agents guess parts of each other’s edges and ignore some information but still get the right answer most of the time? Maybe randomness lets us communicate much less.

\begin{block}{Disjointness is Still Hard — Even with Randomness}

Unfortunately, for \textsc{Disjointness}, randomness does not save us.

Think of the problem like this:
Alice and Bob each hold a set of items.
They want to know whether they share an item.

If they do share even one item,
the answer is NO (not disjoint).
If they share none,
the answer is YES (disjoint).

The difficulty is that the “witness” —
the shared element —
could be in any one of the $n$ positions.

Random guessing does not help much,
because missing that one position leads to the wrong answer.

In fact, it has been proven that even allowing randomness
and a small probability of error,
\textsc{Disjointness} still requires \textbf{maximal \emph{random} communication}.
\end{block}

\begin{enumerate}
\item Top branch corresponds to $x_i$ having the element but not $y_i$.
\item Middle branch corresponds to both $x_i$ and $y_i$ not having the element.
\item Bottom branch corresponds to $y_i$ having the element but not $x_i$.
\end{enumerate}

The logic of the disjoint gadget chain is similar to the equality construction. When we chain the gadgets together, there exists a path from the first gadget to the last
if and only if every gadget is traversable, that is, if and only if $x \cap y = \varnothing$
