\begin{block}{Equality is Maximally Hard}

\begin{columns}[T]

\column{0.5\textwidth}
\hfill \break
\textbf{Equality Problem:} Do Alice and Bob have the same $n$-bit string?

\[
\textsc{EQ}(x,y)=
\begin{cases}
1 & x=y \\
0 & x\neq y
\end{cases}
\]

\vspace{0.5em}

In figure 3, we represent $\textsc{EQ}$ as a communication matrix:

\begin{itemize}
    \item Rows = Alice's input $x$
    \item Columns = Bob's input $y$
    \item Blue dots mark where $\textsc{EQ}(x,y)=1$
\end{itemize}

\bigskip

In communication complexity, a correct protocol must divide this matrix into rectangles that contain either all 0’s or all 1’s. \\

\vspace{0.5em}

But each blue dot is isolated, so in order to cover all $2^n$ diagonal 1’s, the protocol needs at least $2^n$ rectangles. It turns out this implies that Equality requires at least $n$ bits of communication. \\
\vspace{0.5em}

\textbf{Thus, Equality is maximally hard.}

\vspace{0.3em}
In this section, we define a simpler version of the problem from our motivation.

Consider a large graph $G$. Inside $G$, each agent “owns” part of the graph. We call these subgraphs $G_1, G_2, \dots, G_k$. No single player sees the entire graph.

Given a starting vertex $v$ and a target vertex $w$, how much information do the agents need to share about their subgraphs to determine whether there is a path from $v$ to $w$?

For this poster, we will only consider a two agent case.

    \item \ Bot branch corresponds to $x_i = y_i = 0$. 
\end{enumerate}

Consider this gadget where its only traversable from Start to End if both $x_i$ and $y_i$ are both $0$ or $1$. In other words when $y_i=x_i$

\caption{Chain of Equality Gadgets}

To prove that \textsc{Traversal} is also maximally hard, like Equality,
we show that we can reduce \textsc{Equality} to \textsc{Traversal}.

By chaining the gadgets together, we turn each bit comparison into a small “gate.” 
The chain is traversable only if every gate opens, which happens exactly when 
$x_i = y_i$ for all $i$, in other words, when $x = y$.

Therefore, any protocol that solves \textsc{Traversal} can also solve \textsc{Equality}. 
Since Equality is deterministically maximally hard, 
\textbf{\textsc{Traversal} is also deterministically maximally hard.}

\end{block}
